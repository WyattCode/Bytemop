# 优化方案（第三轮审查提出，尚未实施的）

已经实施的优化（窗口先于清理显示、语言包只带 en-US 和 zh-CN、每个列表只查一次语言、进度消息每 100 ms 一次、
固定磁盘列表代替逐个盘符探测、设置页并行加载、长列表 `content-visibility`、未用文案和样式清理）不再列出。
下面按“收益 / 风险”排序，括号里是涉及的文件。

## 值得先做

1. **浏览器 SQLite 放进 worker 线程**（`privacy.js`）。现在 `DELETE` + `VACUUM` 和复制、计数都是同步的，几百 MB 的历史文件会让整个界面卡住数秒。
   收益：大；风险：中（要把 `node:sqlite` 调用和进度/取消搬到 worker）。
2. **每次扫描每个浏览器文件只复制一次**（`privacy.js`）。历史和下载记录各复制一次 History，Cookie 又为“网站列表”复制一次。
   收益：临时文件 I/O 减半以上；风险：低。
3. **隐私“保持登录”名单的增删只重算 Cookie**（`renderer.js`、`privacy-service.js`）。现在每次增删都会重新扫描所有浏览器数据库。
   收益：大；风险：中（需要主进程返回更新后的名单和计数）。
4. **隔离区日志不要每个文件开关一次**（`quarantine.js`）。每移一个文件：追加日志（开-写-关）、移动、提交时再 `lstat` 一遍。
   保持日志文件句柄、边移动边计数，可把 10 万文件的清理缩短 2–3 倍；风险：低（崩溃语义不变）。
5. **清理时复用扫描结果**（`clean-service.js`）。一次清理走两遍目录、查两次进程列表，`lstat` 是串行的。
   传递扫描结果、把 `lstat` 并发限制在 16 左右：2–4 倍；风险：中（数据可能过期，所以每个文件移动前仍要再确认）。

## 之后

6. **重复文件：采样哈希**（`disk-analyzer.js`）。前 64 KB 对虚拟机镜像、ISO、补零文件常常相同；改为头/中/尾各取一段并提前退出，
   再用 2–4 个 worker 并行。收益：I/O 大幅减少；风险：低。
7. **排除项匹配器**（`exclusions.js`）。现在每个文件对每个通配符模式各跑一次 DP（约 0.12 ms），200k 文件 × 20 个 `**` 模式约 23 秒。
   方案：遍历时遇到被排除的目录直接剪枝；模式编译成带上限的正则。风险：中（要证明不会回溯爆炸）。
8. **启动项签名检查分批并缓存到磁盘**（`startup.js`）。一次批量检查只有 60 秒超时，离线时可能整体失败。每批 10 个，结果写缓存。
9. **磁盘分析用 `blocks`/`nlink`/`ino`**（`disk-analyzer.js`）。硬链接已去重；还可以报告“占用空间”而不是逻辑大小（稀疏文件、压缩文件）。
10. **分析队列限制**（`disk-analyzer.js`）。先进先出的限流器让遍历变成广度优先，会把一个超大目录树的所有 `Dirent` 同时留在内存里。改成有界的深度优先。
11. **延迟加载**（`main.js`）。`privacy`、`node:sqlite`、`apps`、`startup` 在第一次用到时再加载，启动更快。
12. **绝对路径启动子进程**（`powershell.js`、`scheduler.js`）。用 `%SystemRoot%\System32\...` 的完整路径，并设置 `stdio: ['ignore','pipe','pipe']`，
    避免依赖当前目录和 PATH。风险：无。
13. **计划扫描的通知门槛**（`scheduled-run.js`）。任何大于 0 字节都弹“发现可清理”；加“至少 50 MB”和“与上次通知相同则不再弹”。
14. **每天一次的到期清理定时器**（`clean-service.js`）。现在只在启动时清理，常开不关的应用几周都不会到期清除。

## 可维护性

16. **渲染进程的重复模式变成辅助函数**：4 份筛选标签（`renderFilters`、启动项、应用、磁盘）合成一个 `chipGroup()`，3 份结果框合成一个 `showBox()`，
    约少 60 行；同时统一“滚动到可见”和错误文案。
17. **测试基础设施**：共用一个临时目录辅助函数并在全局 `after` 里清理；增加一个 Windows 虚拟机 CI；在 `ELECTRON_RUN_AS_NODE` 下跑一遍以对齐 Electron 自带的 Node 版本。
18. **`apps.json`、`privacy.json` 损坏时给“重置”出口**（排除项已经有了）。
