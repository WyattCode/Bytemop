## 1. 要设计的是什么

- **产品**：Bytemop，Windows 清理工具。用户是怕删错东西的普通人。
- **主要任务**：找出可以安全删除的东西，删掉，并且随时能撤销。
- **语汇**：磁盘、字节、扫过、账本、回执（每次操作留下记录，能撤销）。

## 2. 设计令牌

### 颜色（浅色 / 深色）

| 名称 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| Chalk 页面底 | `#f1f3f0` | `#0e181d` | 页面背景 |
| Paper 面板 | `#fcfdfb` | `#142027` | 列表、卡片、侧栏 |
| Ink 文字 | `#17242b` | `#e6eeea` | 正文 |
| Lagoon 强调 | `#0b7566` | `#4fcfb5` | 主按钮、选中、圆环 |
| Amber 谨慎 | `#8f5200` on `#f8ecd2` | `#e8b45f` on `#3a2d14` | 谨慎级标记、警告 |
| Brick 危险 | `#b3261e` | `#c4443b` | 永久删除、错误 |

对比度（已计算）：正文 ≥ 14:1；次要文字 ≥ 5.1:1；强调色文字 ≥ 5.4:1；标记文字（安全/谨慎/高级）≥ 5.3:1；主按钮文字 ≥ 5.6:1。

### 字体

只用系统字体，不引入外部字体（CSP 不允许，也不需要联网）。

- 正文：Segoe UI Variable Text / Segoe UI / Microsoft YaHei UI，14px，行高 1.5。
- 大数字（可释放空间、占用百分比）：Segoe UI Variable Display，字重 300，数字等宽（tabular）。字体本身是设计的一部分，不只是传递内容。
- 字号阶梯：12 / 13 / 14 / 16 / 24 / 34 / 52。标题 600，其余 400。
- 全部用句式大小写，不用全大写、不加字距。

### 形状

圆角随层级变化，而不是一刀切：标记 4px，控件 6px，面板 10px，对话框和欢迎页 14px。
不用投影，只有会浮起来的东西（对话框、抽屉）有一层阴影。结构用 1px 线表达。

```
│  隐私      │                                               │
│  启动项    │                                               │

└────────────┴─────────────────────────────────────────────┘
```

- 侧栏按任务分组（释放空间 / 隐私与启动 / 记录），分组名是句式大小写的小字；窄窗口（< 920px）下分组名变成一条细线，只剩图标。
- 每个页面：左边标题和一句摘要，右边操作。列表是一个带边框的整体，行之间用分隔线，不是一行一张卡片。

## 4. 原则

1. **一个醒目的东西**：概览页的“扫过圆环”。圆环表示已用空间，扫描之后在末端用强调色标出能释放的部分，旁边是大号数字。其余界面保持安静。圆环只在应用打开时画一次（0.8 秒），之后不再重放；系统开启“减少动画”时不播放。
2. **结构即信息**：边框、分隔线、分组名都对应真实的层级，不做装饰。编号只在真正有顺序的地方用（欢迎页的三步）。
3. **反馈要看得见**：按钮悬停变底色、按下下沉 1px；开关、标签页都有明确的选中态；焦点环 2px，所有键盘可达的控件都有。
4. **图标统一**：所有符号用同一套线条 SVG 图标，不用 emoji（盾牌、放大镜、对勾、警告都是）。
5. **文案**：句式大小写；按钮说明会发生什么（“清理所选”），结果里沿用同一个词（“已清理”）；错误说清原因和怎么办；不用装饰性的中点和箭头把短语串起来，改用逗号。

## 5. 对照三个 skill 的检查表

| 规则 | 来源 | 做法 |
|---|---|---|
| 避开“SaaS 卡片套装”：一模一样的圆角卡片、同一个灰阴影、渐变装饰 | frontend-design | 去掉全部阴影和渐变；列表合并成带分隔线的整体；圆角按层级变化 |
| 避开全大写的小标题和字距 | frontend-design | 所有小标题改为句式大小写 |
| 避开用中点串起来的元信息 | frontend-design | 摘要和元信息改用逗号 |
| 不是默认配色（奶油底 + 陶土色，或黑底 + 荧光绿） | frontend-design | Chalk + Lagoon（偏冷的灰绿底，青绿强调）；深色为蓝黑底配柔和薄荷色 |
| 把力气花在一个地方，其余克制 | frontend-design / taste-skill | 圆环是唯一的“大动作” |
| 页面加载时一次有安排的动效，而不是处处动 | frontend-design / taste-skill | 只有圆环绘制一次；没有逐块淡入、没有卡片悬停动画 |
| 对比度 ≥ 4.5:1；焦点可见；尊重减少动画 | ui-ux-pro-max | 已计算；全局 `:focus-visible`；`prefers-reduced-motion` |
| 不用 emoji 当图标，用 SVG | ui-ux-pro-max | 全部换成线条 SVG |
| 语义化颜色令牌，不在组件里写原始色值 | ui-ux-pro-max | 全部走 CSS 变量，深浅色各一套 |
| 控件有足够的点击面积；反馈即时 | ui-ux-pro-max | 按钮最小高度 32px（小按钮 26px，桌面应用常见尺寸），悬停/按下状态 |
| 按钮悬停和按下有反馈；文案朴素 | taste-skill | 悬停换底色、按下下沉 1px；文案去掉修饰 |

## 6. 没有照搬的

- ui-ux-pro-max 建议触控目标 44×44px：这是触屏规则，桌面应用里按钮最小 26–32px，行高 40px 以上，间距 ≥ 8px。
- taste-skill 的整页摄影、着色器背景、分屏章节：属于营销网站，不适用于工具软件。
- “每页一到两个特别时刻”：只做了一个，其余页面刻意保持安静。

## 7. 没验证的

- 在真实 Electron 窗口里的观感（只在浏览器里用模拟数据看了：浅色、深色、720 宽窄窗口、欢迎页）。
- Windows 高对比度主题、屏幕阅读器。
- 中文字体下大数字的字重 300 会回退为常规字重，数字本身来自 Segoe UI Variable，不受影响。
